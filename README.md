# The Sorting Hat's Verdict | XTS Official Merch Campaign

A theatrical interactive web application built for the **Xaverian Theatrical Society (XTS)**. Users experience a Hogwarts-style Sorting Hat ceremony featuring an intelligent 10-question personality quiz, a 30-character theatrical alter-ego roster, dynamic hat facial animations, real-time Web Audio soundscapes, an interactive 3D polo customizer, and 9:16 Instagram Story card generator.

## 🎭 Features

- **Theatrical Velvet Curtains:** Atmospheric entrance with Web Audio sound effects and lighting.
- **Dynamic Sorting Hat:** 8 expressive states, real-time dialogue commentary, and question-by-question facial roulette.
- **30-Character Alter Ego Roster:** 10 theatrical archetypes scored across a 3-Act Temporal Matrix with tie-breaking precedence.
- **Interactive T-Shirt Customizer:** Live front & back toggle with real-time name personalization and position alignment.
- **9:16 Instagram Story Canvas:** High-resolution story card generator with authentic character stills, crests, and dynamic QR stamps.
- **Zero Heavy Audio Files:** 100% synthesized sound design using Web Audio API oscillators (chimes, clicks, fanfares, stage chords).

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript
- **Bundler:** Vite 8
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Effects:** Canvas Confetti & QRCode
- **Deployment:** Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Check types and build production bundle
npm run build

# Preview production build locally
npm run preview
```

## 🌐 Deploy to Vercel

1. Push this repository to GitHub.
2. Import the repository in [Vercel](https://vercel.com).
3. The build settings are pre-configured:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. Deploy!
